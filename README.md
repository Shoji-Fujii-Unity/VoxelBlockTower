# 3D Voxel Block Tower README

## Supported Languages
This game supports the following user interface languages.

### Japanese
日本語に対応しています。
画面上部の言語ボタンで English と切り替えることができます。

### English
This game supports English and Japanese user interfaces.
You can switch between English and Japanese from the language button.

## Game Features
- Title: 3D Voxel Block Tower / 3Dボクセル・ブロックタワー
- Total stages: 100
- Save data: saved locally in the browser
- Sound: can be turned on or off
- Language: can be switched between English and Japanese
- Recommended play area: landscape mode on phones

## How to Play
Tap the game screen on phones, or use Space on PC, to drop the moving block.
The overlapping part is cut and stacked on the tower.
Clear each stage by reaching the required score.

## Controls
- Mobile: tap the game screen
- PC: use Space or Enter
- Pause: use the pause button
- Return to stage select: use the stage select menu

## Save Data
Save data is stored locally in the browser.

Saved information:
- Language setting
- Sound setting
- Stage progress
- Stage best record
- Stage unlock status

## Save File
The current local save name used in this project is:
voxel-3d-block-tower-save-v4

## Supported Browsers
This project uses WebGL and requires a modern browser.

Recommended browsers:
- Chrome
- Edge
- Safari
- Firefox

## Notes
Sound is unlocked after the first user interaction with the page.
This helps avoid browser restrictions related to automatic audio playback.

For offline use, the three.js library file used by this project should be provided locally and referenced locally by the page.
